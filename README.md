# Fișe de Voluntar - Asociația Oportunități și Cariere

## Descriere

Această aplicație web statică este destinată centralizării și prezentării structurate a fișelor de voluntar din cadrul Asociației Oportunități și Cariere. Proiectul oferă un catalog digital interactiv pentru rolurile din echipele tehnice și non-tehnice ale organizației, facilitând accesul la informații clar definite privind atribuțiile, cerințele și competențele asociate fiecărei poziții.

## Funcționalități

- Cuprins organizat pe categorii principale (Fișe Tehnice și Fișe Non-tehnice) și pe departamente.
- Căutare în timp real după titlul rolului sau numele departamentului.
- Navigare laterală ordonată alfabetic pentru comutare rapidă între poziții.
- Afișare detaliată a fiecărei fișe de voluntar: scopul rolului, responsabilități cheie, abilități necesare și dezirabile, beneficii, resurse disponibile, metode de evaluare și competențe dezvoltate.
- Integrarea clasificării profesionale internaționale (coduri O\*NET-SOC) pentru fiecare rol.
